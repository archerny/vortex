# 同步管理页面优化

## 背景与范围

同步批次表原先使用 1410 CSS 像素固定滚动宽度，侧栏展开的笔记本窗口很难直接看到末列。顶部标签与侧栏已经提供导航，两个工具栏仍存在重复入口。本轮调整同步管理的批次表、筛选区和批次／配置工具栏。沿用 [0050 的账户列顺序](0050-2026-11-24-account-display-conventions.md#表格列顺序)及 [0049 的表格内滚动做法](0049-2026-11-23-responsive-trade-records.md)。

## 布局与操作

1. 批次列表收紧列宽和单元格横向留白，前两列为账户名称和 ID。同步日期范围分两行显示，完整的开始和完成时间合在「执行时间」列。保留批次 ID、券商、状态、耗时和各项记录数。
2. 原错误信息列改为「错误 → 查看」，点击后在弹窗读取完整错误。长消息可换行。窄窗口下筛选换行，横向滚动留在表格内部。
3. 删除批次工具栏的「同步配置」按钮，以及配置卡片顶部的「账户管理」和「查看同步批次」。通过顶部标签页切换批次与配置。批次工具栏提供新建同步和刷新，配置卡片顶部提供刷新。行内操作和新建同步缺少就绪连接时的引导沿用现有行为。

## 实施与验收

调整现有 Ant Design 表格与工具栏，复用批次接口。移除工具栏专用的 `onDone` 回调，同步 [前端架构](../knowledge/frontend-architecture.md)和 [前端开发指南](../docs/frontend-guide.md)。合成浏览器验收覆盖侧栏展开的 1280、1366 和 1440 CSS 像素视口，核对末列直接可见、时间完整；在 640 像素验证表格内滚动和筛选换行。点验成功、处理中与清理失败批次、完整错误弹窗、状态筛选、刷新、顶部标签切换和缺少就绪连接的引导。
