# 盈亏分析技术选型演示页

## 背景与目标

用户计划以盘后分析和历史复盘为主扩展股价、期权链和盈亏分析，希望用实际页面比较四种开源工具的效果：TradingView Lightweight Charts、Apache ECharts、Plotly.js 和 Ant Design Table。本次交付可交互的合成数据演示，不连接行情、券商或账本数据。

## 范围与历史方案

- 沿用当前 React、Vite、Ant Design 和 hash 导航，在“盈亏分析”下新增“技术选型 Demo”，路径为 `#/profit-chart-demo`。
- 参考 [0004 相关交易展示](0004-2026-03-12-related-trades-display.md) 的前端组件复用方式，以及 [0015 同步原始数据查看](0015-2026-04-21-sync-staged-data-viewer.md) 的分区展示方式。本次独立增加演示入口，既有业务页和历史设计正文保持原样。
- 新增图表依赖及相应锁定记录，复用现有 Ant Design。同步补齐清单已声明但锁文件缺失的 Vitest，使依赖可以按锁安装；审查既有包版本，避免无关升级。
- 不引入新的路由框架、全局状态库或 TypeScript 迁移；不修改后端、数据库、账本计算或券商同步。

## 设计与关键取舍

1. 页面使用四个标签页，各工具在自己的区域展示真实渲染结果，切换时释放图表实例。按需加载演示页和较重图表，减少对既有页面的影响。
2. Lightweight Charts：K 线、成交量窗格、均线、合成买卖点，支持时间范围切换、十字光标和重置视图；保留官方署名和链接。
3. ECharts：组合净值与回撤、策略到期收益、Delta/Gamma、波动率微笑和行权价×期限热力图，提供参数、图例、缩放或指标切换。
4. Plotly.js：合成波动率曲面及可切换的三维收益曲面，支持旋转、缩放、重置视角；WebGL 不可用或资源加载失败时显示明确错误和重试入口。
5. Ant Design Table：Call/Put 双侧期权链、到期日和范围筛选、指标列切换、排序、虚拟滚动、合约选择以及明细联动。
6. 使用确定性数据生成器；演示标的与期权均为虚构，日期、单位和合成数据标识明确。收益曲线仅用于图形展示，不承诺定价或风控准确性。页面不发起账本或券商请求。
7. 图表封装负责 ResizeObserver、更新及卸载清理，适配 React StrictMode 和窗口大小变化。面板异常局部降级，避免整页空白。

## 实现步骤

1. 写入方案并追加索引；核对所选 Ubuntu 环境的 Node、npm、缓存及临时目录。
2. 通过现有 npm 安装项目依赖，同步锁文件并比较已有包版本。
3. 实现合成数据、图表封装、四类展示面板、页面样式和菜单入口。
4. 核对依赖安装、运行单测和构建，再用浏览器验证图表及交互。
5. 更新当前知识和前端指南；只有满足已有 TODO 的全部验收条件后才更新完成状态。

## 验证与验收

- 在 `ubuntu-dev` 的当前工作树中执行；npm 使用现有缓存，临时目录为 `/tmp`，产物位于工作树内被忽略的目录。
- 在工作树内的干净依赖目录执行 `npm ci`，核对安装不修改清单与锁文件；重复安装核对依赖版本一致。
- 执行前端单测、生产构建和 `git diff --check`，记录退出状态。
- 浏览器从菜单及直接 URL 均可进入；四个工具都实际渲染；验证范围切换、图例/参数、三维旋转或模式切换、期权链筛选/排序/选择及窄屏布局。
- 检查控制台错误、页面切换与卸载、模拟数据标识和图表署名。验证期间不调用真实账本或券商业务接口。
- 若环境不支持 WebGL，记录该限制，验证降级行为，不将三维图显示标为已通过。
