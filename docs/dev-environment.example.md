# 本地开发环境模板

将本文件复制为仓库根目录的 `.dev-environment.local.md`，用实际值替换占位符。按环境分别填写，写明每种任务优先使用哪个环境。例如，前端构建可在宿主机上执行，后端单测可在 Lima 虚拟机中执行。测试和构建命令见 [AGENTS.md](../AGENTS.md#验证与数据安全)。

## <环境名称>

- **适用任务**。<例如后端单测、前端单测与构建，或开发库联调>
- **连接与登录**。<宿主机填写「直接执行」。虚拟机、容器或远程环境填写可从当前终端运行的准确命令，优先提供能执行单条命令并返回退出状态的方式>
- **就绪检查**。<如何确认实例或服务已启动。需要手动启动或登录时，注明所需操作>
- **工作树路径**。<目标环境中当前工作树的绝对路径，或从宿主机工作树路径到目标路径的映射规则>
- **工具与变量**。<任务所需的工具、环境变量及仓库内的缓存和临时目录>
- **联调或迁移**。<仅在需要时填写。记录隔离开发库的连接目标、应用 profile 及配置来源>

认证信息填写现有配置项名称或凭据来源。密码、令牌和私钥保存在各自的凭据存储中。
