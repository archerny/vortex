# 券商同步操作指南

同步管理支持手动提交 IBKR 和 Tiger 的交易记录同步。每次提交创建一个批次，随后由后台拉取、暂存并导入。通过批次列表查看进度和结果，通过刷新获取最新状态。

IBKR 限定为单账户 TCF 和整数订单数量，股票侧行权／指派须精确唯一关联；Tiger 存在未修复的暂存／导入时间格式缺陷。提交入口可用不代表本批导入成功，具体支持范围见各券商指南及 [活动待办](../TODO.md)。

## 提交与查看批次

1. IBKR在**同步管理 → 同步配置**绑定／新建记账账户并将Flex凭证保存到数据库；Tiger仍按所用Spring profile注入凭据。券商须启用且具有对应Broker Code。测试使用隔离合成环境，真实账户不用于自动验证。 [环境与配置说明](../../backend/src/main/resources/README.md)
2. 打开**同步管理 → 同步批次**，点击**新建同步**，选择券商和日期范围。可用券商由后台适配器发现接口提供。
3. 提交后查看批次列表。批次提交成功只表示任务进入后台，完成状态和错误信息以刷新后的批次为准。HTTP 409 表示已有批次占用同步名额。 [故障排查与恢复](recovery.md)
