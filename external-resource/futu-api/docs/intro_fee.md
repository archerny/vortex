 行情
--------------------------------------------------------------------

中国内地 IP 个人客户，免费获取港股市场 LV2 行情及 A 股市场 LV1 行情。  
部分品种行情，需要购买行情卡后方可获取。您可以在 [行情权限](https://openapi.futunn.com/futu-api-doc/intro/authority.html#2867)
 一节，进入具体的行情卡购买页面查看价格。
