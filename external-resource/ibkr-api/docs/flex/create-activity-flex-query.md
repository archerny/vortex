Create an Activity Flex Query
=============================

##### Instructions

You create Activity Flex Queries on the Custom Flex Queries screen.

1.  Click **Performance & Reports > Flex Queries.**
    
    *   Alternatively, click **Menu** in the top left corner > **Reporting > Flex Queries.**
        
2.  If you manage or maintain multiple accounts, the Account Selector opens. Search for and select an account.
    
    The Flex Queries screen opens.
    
    ![The flex queries panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/flex.jpg "Flex Queries")
    
3.  Click the **+** icon in the top right corner of Activity Flex Query.
    
    ![The create an activity flex query panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/create%20activity%20flex%20query.png "Create an Activity Flex Query")
    
4.  Enter the name of the Activity Flex Query.
    
    ![The query name field when creating an activity flex query in portal. ](https://www.ibkrguides.com/clientportal/resources/images/activityflexname.jpg "Create an Activity Flex Query Enter Name")
    
5.  In **Sections**, click each section that you want to appear in your Flex Query.
    
    ![The activity flex query sections panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/activityflexsections.jpg "Activity Flex Query Sections")
    
6.  As you select each section, a pop-up opens with all possible fields in the selected section.
    
    *   Click each field that you want to appear in the Flex Query.
        
    *   Change the order in which the fields will appear by dragging each field to a different position using the bars symbol on the right.
        
    *   Click **Save**.
        
    
    ![The activity flex query account information panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/activityflexfields.jpg "Activity Flex Query Account Information")
    
7.  In the **Delivery Configuration** section, choose how you want the report delivered.
    
    *   **Accounts** - Click Add/Edit Accounts to bring up the Account Selector.
        
    *   **Models** - Choose Optional or All.
        
    *   **Format** - Choose XML, CSV, Text (Pipe) or Text (Tab).
        
    *   **Period** - Choose Last Business Day, Last Business Week, Last Month, Last Quarter, Last 30 Calendar Days, Last 365 Calendar Days, Last N Calendar Days, Month to Date, Quarter to Date or Year to Date.
        
    
    ![The activity flex query delivery configuration panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/deliveryconfiguration.jpg "Activity Flex Query Delivery Configuration")
    
8.  Choose other options for your report in the **General Configuration**section.
    
    ![The activity flex query general configuration panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/generalconfig.jpg "Activity Flex Query General Configuration")
    
9.  Click **Continue** to review your Activity Flex Query configuration. Click **Create** to create the report or **Back** to return to the previous screen to make any changes.
    
    ![Image of the review your activity flex query panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/reviewactivityflexquery.jpg "Review Your Activity Flex Query")
