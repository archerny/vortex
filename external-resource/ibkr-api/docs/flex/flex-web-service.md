Enable Flex Web Service
=======================

##### Instructions

The Flex Web Service lets you access your pre-configured flex queries via HTTPS protocol without logging into Client Portal. This feature lets you write automated client software in your preferred language and request previously defined Flex queries.

[Who Can Access the Flex Web Service Page?](./flex-web-service.md)

You can access this page if you are a(n):

*   Individual, Joint, Trust or IRA Account User
*   Small Business Account User
*   Family Advisor, Non-Professional Advisor or Client User
*   Advisor Master User Individual
*   Advisor Master User Organization
*   Advisor Client User Individual
*   Advisor Client User Organization
*   Proprietary Trading Group Master User
*   Proprietary Trading Group Sub User
*   Broker Master User (Master Account only)
*   Broker Client User
*   Broker Client User Organization
*   Investment Manager Master User
*   Fund

1.  Click **Performance & Reports** followed by **Flex Queries > Flex Web Service Configuration.**
    
    *   Alternatively, click **Menu** in the top left corner > **Reporting > Flex Queries > Flex Web Service Configuration.**
        
    
    ![Image of the flex web services configuration widget in portal. ](https://www.ibkrguides.com/clientportal/resources/images/configure%20flex%20web.png "Flex Web Services Configuration Widget")
    
2.  Select the configure gear icon ![Image of the gear icon in portal. ](https://www.ibkrguides.com/clientportal/resources/images/configurewheelicon.jpg "Gear Icon")
    
3.  Click the toggle button to enable or disable the Flex Web Service.
    
    ![The configure flex web services panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/configure%20flex%20web%202.png "Configure Flex Web Services")
    
4.  A new token will appear to initiate Flex Query Requests.
    
5.  Click **Generate A New Token** to invalidate the prior token. Select the amount of time for expiration and a valid IP address (optional).
    
6.  Click the **x** button to return to the Account Settings screen.
