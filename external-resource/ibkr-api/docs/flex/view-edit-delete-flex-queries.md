View, Edit, and Delete Flex Query Templates
===========================================

##### Instructions

The Custom Flex Query screen displays all your saved custom Activity and Trade Confirmation Flex Queries. Custom Flex Queries are saved as templates. On the Custom Flex Queries screen, you can:

*   View all of your saved Activity and Trade Confirmation Flex Query templates.
*   Edit an existing template.
*   Delete an existing template.
*   Create a new [Activity Flex Query](./create-activity-flex-query.md)
     or [Trade Confirmation Flex Query](./create-trade-confirmation-flex-query.md)
     template.

[View a Saved Flex Query Template](./view-edit-delete-flex-queries.md)

1.  Click **Performance & Reports > Flex Queries**.
    
    *   Alternatively, click **Menu** in the top left corner > **Reporting > Flex Queries**.
        
2.  If you manage or maintain multiple accounts, the Account Selector opens. Search for and select an account.
    
    The Flex Queries screen opens.
    
    ![The flex queries panel in portal. ](https://www.ibkrguides.com/clientportal/resources/images/flex.jpg "Flex Queries")
    

[Edit a Saved Flex Query Template](./view-edit-delete-flex-queries.md)

1.  Follow the previous steps.
2.  Click the **Edit** (pencil) icon for the template. Make changes as required.

[Delete a Saved Flex Query Template](./view-edit-delete-flex-queries.md)

1.  Follow the previous steps.
2.  Click the **x** icon for the template. Once you delete a template, you can no longer run that statement.
