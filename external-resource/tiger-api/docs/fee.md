# 交易与行情费用

交易费用

[](./fee.md#%E4%BA%A4%E6%98%93%E8%B4%B9%E7%94%A8)

------------------------------------------------------------------------------------

通过 OpenAPI 进行交易**没有附加收费**，交易费用与通过 APP 交易的费用一致。具体收费标准可参考[官网收费说明](./contact.md#commission_link)
。

  

行情费用

[](./fee.md#%E8%A1%8C%E6%83%85%E8%B4%B9%E7%94%A8)

------------------------------------------------------------------------------------

OpenAPI 的行情权限**独立于 PC/APP**，需单独购买。

不会与 PC/APP 行情权限互相抢占。

OpenAPI 提供的行情**延迟更低、更新更快**。

> ⚠️
> 
> **CAUTION**
> 
> 如您在多台设备上同时调用 API 获取行情数据，可参考 [grab\_quote\_permission](./quote-common.md#grab_quote_permission)
>  接口说明进行处理。

  

行情购买

[](./fee.md#%E8%A1%8C%E6%83%85%E8%B4%AD%E4%B9%B0)

------------------------------------------------------------------------------------

**个人客户**行情权限有两种购买方式：

1.  [开发者信息页](https://developer.itigerup.com/profile)
    购买；
2.  在APP 购买，页面路径：Tiger Trade APP - 我的 - 行情权限商店 -API。

**机构客户**在 [机构中心](./contact.md#institution_link)
 购买，页面路径：用户管理-市场数据- API市场数据。
