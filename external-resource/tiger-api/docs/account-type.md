# 用户与账户类型

用户类型

[](./account-type.md#%E7%94%A8%E6%88%B7%E7%B1%BB%E5%9E%8B)

---------------------------------------------------------------------------------------------

Open API 面向两类主要用户：

*   **个人投资者**：只需完成老虎证券线上开户并入金，即可申请开通 API 使用权限。个人用户可通过 [API权限开通页面](https://developer.itigerup.com/profile)
    完成认证，开通后即可参考快速入门文档进行接入。
*   **机构投资者**：可通过老虎证券机构后台提交开发者信息注册并开通 API 权限。详情见[机构账户中心](./contact.md#institution_link)
    。

如在开通过程中遇到问题，请[**联系我们**](./contact.md)
。

  

账户类型

[](./account-type.md#%E8%B4%A6%E6%88%B7%E7%B1%BB%E5%9E%8B)

---------------------------------------------------------------------------------------------

*   **综合账户（实盘）**：支持全部市场类型，融资融券功能支持部分股票，支持股票、窝轮、牛熊证、期权和期货交易，账户类型包括保证金和现金，支持任意时段下单
*   **环球账户（实盘）**：不推荐，支持全部市场类型，融资融券功能支持部分股票，支持股票、期权和期货交易，账户类型包括保证金和现金，支持任意时段下单
*   **模拟账户**：支持美股、港股和A股交易，支持期权交易

**账户类型对比**

| 特性  | 综合账户 | 环球账户 | 模拟账户 |
| --- | --- | --- | --- |
| 账户性质 | 实盘  | 实盘  | 虚拟资金 |
| 推荐状态 | 推荐  | 不推荐（旧版） | 适合测试 |
| 支持市场 | 美股、港股、A股（沪港通/深港通）、新加坡、澳洲 | 美股、港股、A股（沪港通/深港通）、新加坡、澳洲 | 美股、港股、A股 |
| 股票交易 | 支持  | 支持  | 支持  |
| 期权交易 | 支持  | 支持  | 支持  |
| 期货交易 | 支持  | 支持  | 不支持 |
| 窝轮/牛熊证 | 支持  | 不支持 | 不支持 |
| 融资融券 | 支持（部分股票） | 支持（部分股票） | 不支持 |
| 账户类型 | 保证金/现金 | 保证金/现金 | —   |
| 盘前盘后下单 | 支持  | 支持  | 支持  |

> 💡
> 
> 综合账户是目前推荐的实盘账户类型，功能最全面。环球账户为旧版账户类型，新用户请选择综合账户。模拟账户适合开发测试，无需入金即可使用。
