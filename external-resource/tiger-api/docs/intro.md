# 简介

老虎开放平台可以为个人开发者和机构客户提供接口服务。为便于用户使用，我们开发了 Open API SDK。Open API SDK中封装了老虎底层的接口，允许在用户自选的编程语言（目前支持 Java/Python/C++/C#）编写的交易程序中方便地调用 Open API 接口，以使用老虎的行情、交易及推送服务。目前老虎 API 支持操作用户 ID 下的全部类型的账户，包括综合账户、环球账户和模拟账户。

面向用户

[](./intro.md#%E9%9D%A2%E5%90%91%E7%94%A8%E6%88%B7)

--------------------------------------------------------------------------------------

主要适用于具备一定开发能力，并对量化策略有研究的**个人**或**机构**投资者。

核心功能

[](./intro.md#%E6%A0%B8%E5%BF%83%E5%8A%9F%E8%83%BD)

--------------------------------------------------------------------------------------

*   **账户信息**：查询账户资产与持仓情况
*   **交易管理**：创建、修改、撤销订单；查询订单状态与成交明细
*   **行情查询**：获取股票、期权、期货、窝轮、牛熊证等行情，支持选股器与轮证筛选
*   **实时推送**：订单变动、资产与持仓更新、行情变动

交易订单类型

[](./intro.md#%E4%BA%A4%E6%98%93%E8%AE%A2%E5%8D%95%E7%B1%BB%E5%9E%8B)

----------------------------------------------------------------------------------------------------------

支持多种订单类型满足不同交易策略与风险控制需求：

*   市价单、限价单、止损单、止损限价单、跟踪止损单、附加订单
*   算法订单：TWAP、VWAP

免费使用

[](./intro.md#%E5%85%8D%E8%B4%B9%E4%BD%BF%E7%94%A8)

--------------------------------------------------------------------------------------

完成开户并入金后，您即可开通并使用 Open API。费用规则如下：

**交易费用**：通过 Open API 交易与 APP 一致，无额外费用，交易佣金及其他收费参照老虎官网的[收费说明](./contact.md#/commission_link)

> ⚠️
> 
> **CAUTION**
> 
> **行情费用**API行情权限独立于APP，需要单独购买，详情请见[收费及权限](./fee.md#/)
